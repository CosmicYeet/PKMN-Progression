    Make it your own · spreadsheet setup

    In the league spreadsheet, add a tab named Wheel. Paste the starter table below into A1. You can rename options, change descriptions, or add rows.

    Columns A–C remain Option, Chance (%), and Description. Optional pack automation uses D: Effect (packs), E: Set, and F: Quantity. Existing descriptions such as “Open 3 packs of Base Set” are also recognized automatically. Active chances must add up to 100; use 0 to disable a row.

    Save your changes in Sheets, then choose Refresh options above. Invalid chances disable spinning until fixed or you explicitly choose the starter options. If the tab cannot be read, the page clearly labels its starter fallback.

    Approve pack rewards

    Add a spreadsheet tab named Bonus Pulls with these headers in A1:E1: Player, Set, Packs, Pull Link, Approved. Paste a copied claim into the next empty row, then set Approved to TRUE only after checking it. Approved links are merged into that trainer’s collection during the next manual card-pool build.

    The sheet uses the same public read access as the schedule. Never put passwords or private data here. There is no enforced spin limit; the Approved column is the Commissioner’s safeguard.
